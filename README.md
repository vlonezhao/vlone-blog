# vlone-blog

基于 **Next.js 15 + React + Tailwind CSS + MDX** 搭建的个人博客。  
支持文章列表、文章详情页，未来会逐步完善搜索、标签分类、评论等功能。

---

## 🚀 本地运行

```bash
# 克隆仓库
git clone https://github.com/vlonezhao/vlone-blog.git
cd vlone-blog

# 安装依赖（推荐 pnpm）
pnpm install

# 本地开发
pnpm dev


# 代码提交规范
type（类型）

feat: 新功能

fix: 修复 bug

docs: 文档修改

style: 代码格式（空格、缩进等，不影响逻辑）

refactor: 代码重构（不影响功能）

test: 增加或修改测试

chore: 构建或工具配置的更改
